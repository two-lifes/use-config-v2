# Use Config v2 — правила работы агента

Расширение Google Chrome (Manifest V3) для каталога сайтов и учётных данных по
темам. Проект начат с нуля 2026-10-26 и заменяет WPF-приложение из
`../use-config` (D-01). Старый проект не изменять и ничего из него не переносить.

## Разрешения

- Обсуждение, вопрос, просьба о плане или документации не разрешают писать код.
- Код, зависимости и настройку сборки начинай только по явной команде на
  реализацию или по вызову `/next-task`.
- Команда изменить документацию разрешает менять документы без дополнительных
  подтверждений.
- После явного поручения доводи задачу до результата в согласованном объёме,
  не спрашивай «продолжать?» после каждого шага.
- По просьбе остановиться прекрати работу и не возобновляй её по более ранней
  команде.
- Решения со статусом **Proposed** не считай согласованными: перед реализацией
  зависящего от них поведения спроси пользователя, если он ещё не ответил.
  Не выдавай своё предложение за решение пользователя.

## Команда next-task

`/next-task` выполняет ровно один следующий пункт `X.Y` из
[docs/tasks.md](docs/tasks.md) по навыку
[.claude/skills/next-task/SKILL.md](.claude/skills/next-task/SKILL.md).
Вызывается только явно; обсуждение команды не является её вызовом. Вызов не
подтверждает открытые решения и не разрешает коммит и push: отметки, коммит и
push предлагаются после выполнения и проверок.

## Команды проекта

- `npm install` — установка зависимостей (версии закреплены в `package.json`).
- `npm run typecheck` — `tsc --noEmit` для `src` и для тестов
  (`tests/tsconfig.json`).
- `npm run build` — проверка типов и сборка расширения в `dist/`.
- `npm run lint` — ESLint (typescript-eslint).
- `npm run format` — форматирование Prettier (Markdown исключён).
- `npm run format:check` — проверка форматирования Prettier.
- `npm run test:unit` — unit-тесты Playwright (`tests/unit`).
- `npm run test:e2e` — сборка и e2e-тесты расширения в headless Chromium
  (`tests/e2e`).
- `npm run check` — все проверки: типы, линтер, форматирование, unit, сборка и
  e2e.

Подробнее о тестах — в [docs/technical.md](docs/technical.md#testing).

## Проверки

- После изменений кода запускай проверки из раздела «Команды проекта»,
  соответствующие изменению; в конце этапа — полный `npm run check`.
- Расширение проверяется в headless Chromium из Playwright в этой среде
  (Linux/WSL2). Google Chrome здесь не установлен; ручную проверку в Chrome
  делает пользователь (пункты 4.3 и 5.5).
- Для текстовых изменений документации сборку и тесты не запускай; проверяй
  ссылки, нумерацию задач и согласованность требований.
- Не отмечай непроверенное выполненным и сообщай, что не проверено.
